# data09-22 · 용접누락 방지 검출

## 실행 방법

**온라인에서 바로 쓰기: https://aebonlee.github.io/data09-22/**

내 PC 에서 쓰려면 이 폴더의 `index.html` 을 더블클릭해 크롬·엣지로 엽니다. **인터넷 없는 사내 PC 에서도 동작합니다(폐쇄망 모드 기본 켬)** — 외부 라이브러리·CDN 을 부르지 않고(SheetJS·JSZip 은 `vendor/`), 성적서와 사진은 이 브라우저 안에서만 읽습니다.

처음에는 **「예시 성적서 불러오기」** 를 눌러 보세요. 가상 협력사·가명(용접사A 등)·코드로 그린 용접 그림으로 만든 예시 3개(시트 7장)에 일부러 넣은 문제가 들어 있습니다: 검사일 「월 일」 그대로, 위치 F 사진 없음, 다른 Serial 사진 재사용(같은 파일 · 밝기만 바꾼 것), 누락 그림, 각장 기준 밖 값, 빈 Arm 시트, 검사자 빈칸.

| 메뉴 | 하는 일 |
|---|---|
| 성적서 올리기 | .xlsx 여러 개를 끌어다 놓기. 시트마다 양식(위치 A~F 성적서 / 위치 번호 보고서)·머리칸·위치별 실제 사진 수. .xls 는 .xlsx 로 저장하는 방법 안내 |
| 자동 점검 | 규칙만으로(AI 없음): 검사일 빈칸·양식 글자, Serial·용접사·검사원 빈칸, 실제 사진 없는 위치, 「정량적 기입」인데 OK 만, 각장 기준 밖, 같은 사진 재사용(파일 지문 + 모양 지문), 빈 시트, 기록된 용접누락. CSV |
| 사진 판정 | 위치마다 가이드(도면 각장)와 실제 사진을 나란히, 누르면 확대. 사람이 양호 / 누락 의심 / 판독 불가 확정. 폐쇄망 모드를 끄면 AI 도우미(요청문 복사 또는 내 OpenAI 키) — 제안만 |
| 용접사별 누적 | 판정한 위치 · 누락 의심 · 판독 불가 · 비율, 협력사·기종 거르기, CSV |
| 설정·데이터 | 폐쇄망 모드, AI 키, 미리보기 저장, 백업·복원, 폐쇄망 사용법 |

- **사진 원본은 저장하지 않습니다.** 저장소(localStorage)에는 성적서 분석 결과, 사진 지문, 긴 변 96px 미리보기(끌 수 있음), 판정 기록만 남습니다.
- 로직 테스트: `node test/logic.test.mjs` (설치할 것 없음)
- 예시 파일 다시 만들기: `node scripts/make-samples.js`
- DB 스크립트 검증: `./scripts/sqltest/run.sh` (로컬 PostgreSQL 필요)

## 1단계 구현 범위

| 기능 (제출 기획서) | 상태 | 1단계에서 한 것 / 남은 것 |
|---|---|---|
| 위치별 사진 등록 | 완료 | 기존 엑셀 성적서를 그대로 읽어 위치별 배정(두 양식), 위치별 필수 사진 누락 검출 |
| 엑셀 기록 기반 강제 알림 | 완료(화면) | 결과표 「용접누락」이 OK 가 아니면 오류. 메일 알림은 다음 단계 |
| 성적서 작성 품질 점검 | 완료 | 검사일·빈칸·OK 만 기입·각장 기준·같은 사진·빈 시트 (샘플에서 새로 보인 항목) |
| 용접누락 판독 | 대체 | 사람이 판정, AI 는 제안만(폐쇄망 모드에서 꺼짐). **AI 판독 검증은 라벨 사진 받은 뒤 2단계** |
| 판정 이력·용접자별 불량률 | 완료 | 판정 기록(덧붙이기만) + 용접사별 누적·CSV, DB 스키마 준비 |
| 업로드 시점 자동 판별 · 메일 공유 · 품질 판별 | 다음 단계 | 구현 방식(포털 연동·매크로) 결정 후 |
