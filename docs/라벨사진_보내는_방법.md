# 라벨 사진 보내는 방법 (2단계 AI 판독 파일럿용)

2026-10-01 오전에 보내 주실 정상/비정상 사진을 받는 형식입니다. 이 사진과 라벨이 2단계의 **정답표**가 됩니다 — AI 나 사람이 누락을 몇 장 놓치는지(누락 미검출), 정상을 몇 장 누락으로 잘못 잡는지(오탐)를 이 표와 대조해 셉니다.

## 1. 폴더 모양

```
라벨사진_20261001_김무연/
  정상/
    VDK14W_SJ25D58_B.jpg
    VDK14W_SJ25D58_E.jpg
  누락/
    VDK14W_SJ25D60_B.jpg
    VDK14W_SJ25D60_E_1_윗면비드없음.jpg
    VDK14W_SJ25D60_E_2.jpg
  경계/
    VDK14W_SJ25D57_E_어두움.jpg
```

- **맨 위 폴더**: `라벨사진_보낸날짜_이름` — 여러 번 보내도 섞이지 않게 합니다.
- **라벨 폴더는 세 가지만**: `정상` · `누락` · `경계`.
  - `정상` — 가이드에 표시된 용접선이 모두 용접된 사진.
  - `누락` — 용접선 중 하나라도 용접이 안 된(또는 일부만 된) 사진.
  - `경계` — 사람이 봐도 판단이 어려운 사진(어두움·그을음·초점 흐림·해당 부위가 잘림). 판정이 확정된 사진이라도 사진만 보고 가리기 어려우면 여기에 넣고 메모에 실제 결과를 적어 주세요(예: `_실제정상`).
- 라벨 폴더 안에 하위 폴더(기종별 등)가 더 있어도 됩니다.

## 2. 파일 이름

`기종_Serial_위치[_번호][_메모].jpg`

| 칸 | 쓰는 법 | 예 |
|---|---|---|
| 기종 | 성적서 「기종」 칸 그대로(밑줄 `_` 없이) | `VDK14W` |
| Serial | 성적서 「Serial No.」 칸 그대로 | `SJ25D60` |
| 위치 | 성적서 위치 A~F, 공정 검사 보고서는 1·2 | `B` |
| 번호 (선택) | 같은 위치에 여러 장이면 1, 2, 3 | `_1` |
| 메모 (선택) | 무엇이 보이는지 짧게. 띄어쓰기 대신 붙여 쓰기 | `_윗면비드없음` |

- **한 파일 = 한 위치.** 성적서에서 꺼낸 사진이든 새로 찍은 원본이든, 한 장에 한 위치만 담아 주세요.
- 형식은 jpg·png. 가능하면 **원본 촬영본**(성적서에 붙은 축소본이 아닌 것)을 주시면 AI 판독에 유리합니다. 성적서에서 꺼낸 사진만 있다면 그것도 괜찮습니다.

## 3. 무엇을 먼저

1. **Serial 끝 60(SJ25D60)의 B·E** — 확인된 불량입니다. `누락` 에 넣어 주세요.
2. **같은 기종의 다른 Serial(57·58·61 등) B·E 정상 사진** — 60 과 견줄 기준입니다.
3. 그 밖의 위치(A·C·D·F)와 다른 기종·협력사 사진, `경계` 사례.

정상과 누락의 수가 크게 달라도 괜찮습니다. 다만 누락이 적을수록 「누락 미검출 0건」을 확인하는 힘이 약해지니, 누락 사진은 있는 만큼 모두 주시면 좋습니다.

## 4. 받은 뒤 하는 일

1. 도구의 **「라벨 사진」** 메뉴에서 폴더를 고릅니다. 사진 내용은 읽지 않고 이름만 봅니다.
   - 위치별 정상/누락/경계 개수, 이름이 규칙에 맞지 않는 파일, 같은 Serial·위치에 라벨이 엇갈린 파일을 보여 줍니다.
   - 「라벨 표 CSV」를 내려받습니다(경로 · 라벨 · 기종 · Serial · 위치 · 번호 · 메모).
2. 이름이 틀린 파일은 보내 주신 분께 확인 후 고칩니다(추측으로 라벨을 붙이지 않습니다).
3. 2단계 성능표: 라벨 표 기준으로 사람 판정·AI 제안의 누락 미검출 · 오탐 · 판독 불가 비율을 위치별로 셉니다.

## 5. 보관

- **사진은 이 공개 저장소에 올리지 않습니다.** 협력사 제품 사진이고 원본에 이름·Serial 이 적혀 있습니다. 강사 PC 의 리포 밖 폴더에서만 다룹니다.
- 저장소에는 라벨 표의 **개수·결과(성능표)** 만, 이름·Serial 을 가린 형태로 기록합니다.
